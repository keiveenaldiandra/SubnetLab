Menghitung Subnet

Temukan network, broadcast, wildcard, dan rentang host langkah demi langkah.

Tujuan belajar

  • Menentukan blok tempat sebuah IP berada.
  • Menghitung network, broadcast, dan rentang host.
  • Memeriksa hasil dengan kalkulator subnet.

Menentukan network address

Network address diperoleh dari operasi AND antara bit alamat IP dan subnet mask. Bit host menjadi 0. Untuk 192.168.10.77/26, operasi pada oktet terakhir adalah 01001101 AND 11000000 = 01000000, atau 64.

  1. Ubah /26 menjadi mask 255.255.255.192.
  2. Ukuran blok pada oktet terakhir = 256 − 192 = 64.
  3. Batas blok: 0–63, 64–127, 128–191, dan 192–255.
  4. Angka 77 berada dalam blok 64–127. Network address adalah 192.168.10.64.

Broadcast dan host usable

Broadcast address adalah alamat terakhir pada subnet biasa, dengan seluruh bit host bernilai 1. Untuk blok 64–127, broadcast-nya 192.168.10.127. Host pertama adalah network + 1 dan host terakhir adalah broadcast − 1.

Rentang host pada contoh ini adalah 192.168.10.65 sampai 192.168.10.126, sebanyak 62 host. Alamat network dan broadcast tidak diberikan kepada perangkat pada subnet biasa. Pengecualian /31 untuk point-to-point dan /32 dijelaskan di modul sebelumnya.

Wildcard dan pengecekan hasil

Wildcard adalah kebalikan setiap bit subnet mask. Kurangi masing-masing oktet mask dari 255: mask 255.255.255.192 menghasilkan wildcard 0.0.0.63.

Buka kalkulator dan masukkan 192.168.10.77 dengan prefix /26. Cocokkan hasilnya dengan tabel. Geser ke /24 lalu perhatikan perubahan network menjadi 192.168.10.0 dan broadcast menjadi 192.168.10.255.

Latihan mandiri

Tentukan network, broadcast, dan rentang host untuk 192.168.1.130/27.

Lihat pembahasan

Ukuran blok /27 adalah 32. Alamat 130 berada pada blok 128–159. Network: 192.168.1.128; broadcast: 192.168.1.159; host: 192.168.1.129–192.168.1.158, sebanyak 30 host.
