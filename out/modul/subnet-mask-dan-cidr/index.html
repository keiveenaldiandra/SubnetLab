Subnet Mask dan CIDR

Baca prefix, subnet mask, ukuran blok, dan kapasitas host.

Tujuan belajar

  • Mengubah prefix menjadi subnet mask.
  • Menghitung jumlah alamat dalam satu blok.
  • Memahami penggunaan khusus /31 dan /32.

Hubungan subnet mask dan prefix

Subnet mask berisi deretan bit 1 untuk bagian network, lalu bit 0 untuk bagian host. CIDR menuliskan jumlah bit network setelah garis miring. Prefix /24 berarti 24 bit 1 diikuti 8 bit 0, sehingga mask-nya 255.255.255.0.

Pada /26, mask binernya adalah 11111111.11111111.11111111.11000000. Oktet terakhir bernilai 128 + 64 = 192, sehingga subnet mask-nya 255.255.255.192.

Ukuran blok dan kapasitas host

Jumlah bit host adalah 32 − prefix. Jumlah seluruh alamat dalam blok adalah 2 pangkat jumlah bit host. Untuk subnet biasa hingga /30, dua alamat dipakai sebagai network dan broadcast, sehingga host usable = 2^(32 − prefix) − 2.

Prefix /26 memiliki 6 bit host, 64 alamat, dan 62 host usable. Dalam satu /24 terdapat empat blok /26, dimulai pada oktet terakhir 0, 64, 128, dan 192. Semakin besar prefix, semakin kecil blok alamatnya.

Kasus khusus /0, /31, dan /32

Prefix /0 mencakup seluruh ruang alamat IPv4 dan sering dipakai pada rute default. Perhitungan kapasitas secara matematis tidak berarti seluruh alamat tersebut dapat diberikan ke perangkat; ada alamat dengan fungsi khusus.

Pada sambungan point-to-point /31, kedua alamat dapat menjadi alamat endpoint sesuai RFC 3021, sehingga tersedia 2 host tanpa broadcast terpisah. Prefix /32 menunjuk tepat satu alamat, misalnya rute host atau alamat loopback. Rumus pengurangan dua tidak berlaku untuk kedua kasus ini.

Perbandingan prefix

Kapasitas berikut berlaku untuk subnet biasa, dengan pengecualian /31 dan /32 seperti dijelaskan di atas.

/24 · 255.255.255.0
256 alamat · 254 host
/26 · 255.255.255.192
64 alamat · 62 host
/30 · 255.255.255.252
4 alamat · 2 host
/31 · 255.255.255.254
2 alamat · 2 endpoint point-to-point
/32 · 255.255.255.255
1 alamat

Latihan mandiri

Berapa subnet mask, jumlah alamat, dan host usable pada /27?

Lihat pembahasan

Mask /27 adalah 255.255.255.224. Tersisa 5 bit host, sehingga ada 2^5 = 32 alamat dan 32 − 2 = 30 host usable.

Bacaan lanjutan

  • RFC 4632 — Classless Inter-domain Routing
  • RFC 3021 — 31-Bit Prefixes on Point-to-Point Links
